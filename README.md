# ふたりの行きたいお店

行きたいお店をリスト化して、ふたりで共有するための静的Webページです（`index.html` 1ファイルで完結）。

## 機能

- **お店一覧**：店名・エリア・ジャンル・雰囲気・Google マップ／食べログ／Instagram のリンク・メモ・「行った／行きたい」を登録
- **検索・絞り込み**：エリア・ジャンル・雰囲気・状態・キーワード（一覧とマップで共通）
- **マップ**：お店の位置をピン表示。Google Maps API キーを設定すると Google マップ、未設定なら OpenStreetMap
- **共有**：共有リンク（URL にリストを圧縮して埋め込み）または JSON ファイルで受け渡し、受け取った側で「統合」

## 公開（GitHub Pages）

1. このリポジトリを GitHub に push
2. リポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `/ (root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## データの保存場所について

- お店のデータは **各端末のブラウザ（localStorage）** に保存されます。リポジトリやサーバーには保存されません。
- そのため、公開URLを他人が開いても、あなたのリストは見えません（空のリストが表示されます）。
- 相手と同期するには「設定・共有」タブの **共有リンクを作成** → LINE などで送る → 相手が開いて **統合する** を選びます。
- ブラウザのデータを消すとリストも消えるので、ときどき **JSONを書き出す** でバックアップしてください。

## Google Maps API キー（任意）

Google Cloud Console で Maps JavaScript API と Geocoding API を有効化してキーを作成し、
**アプリケーションの制限 → ウェブサイト** に `https://<ユーザー名>.github.io/*` を設定してから、
ページの「設定・共有」タブに入力してください。キーは入力した端末にのみ保存されます。
