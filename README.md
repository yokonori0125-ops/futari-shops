# 美味しいもの食べいこ！

「美味しいもの食べいこ！」は、行きたいお店をリスト化して、**招待した人（最大10人）と、リアルタイムに共有**する Web アプリです。
画面は `index.html` 1ファイル（GitHub Pages で公開）、データは Firebase（Authentication + Firestore）に保存します。

公開URL: https://yokonori0125-ops.github.io/futari-shops/

## 機能

- **お店一覧**：店名・エリア・ジャンル・雰囲気・Google マップ／食べログ／Instagram のリンク・メモ・「行った／行きたい」
- **食べログの画像**：食べログのリンクを登録すると、お店トップの画像（リンクプレビュー用の og:image）を一覧に表示。
  ブラウザから食べログを直接読めないため、外部サービス（[Microlink](https://microlink.io/)、予備に [Jina Reader](https://jina.ai/reader/)・[AllOrigins](https://allorigins.win/)）経由で取得し、取得した画像URLをリストに保存してメンバーにも共有
- **食べログの評価**：食べログの点数（1.00〜5.00）を星と数字で一覧に表示し、「食べログ評価が高い順」で並べ替え可能。
  取得はお店の登録時と、その後は最長で週1回だけ（取得した点数はリストに保存してメンバーにも共有）
- **ジャンルの自動選択**：食べログのリンクを貼ると、食べログのカテゴリ（ページタイトル「店名 (駅/カテゴリ) - 食べログ」から取得）をジャンルに反映。
  近いジャンルがあればそれに合わせ（例: 中華料理→中華）、無ければカテゴリ名で追加。反映はリンクを貼った・変えたときと、既存のお店へ1回だけ（追加のみ）で、編集画面でいつでも手動で変更できる
- **配色・背景の柄**：設定タブで背景色・強調色（ボタンや印の色）・背景の柄（ドット／ストライプ／方眼／ギンガム／波／ジグザグ）を選べる。背景の明るさに合わせて文字色は自動で切り替わる（端末ごとに保存）
- **気分で探す**：ジャンル・雰囲気・メモ・食べログ評価から、お店に合う気分（うれしい・ときめき・癒やされる など14種）を自動で付与。
  検索欄に「うれしい」「疲れた」などと入れると、その気分に近いお店を近い順に表示（言い換え・今の状態からの読み替えに対応）
- **検索・絞り込み**：エリア・ジャンル・雰囲気・状態・キーワード（一覧とマップで共通）
- **マップ**：お店の位置をピン表示（Google Maps API キー設定時は Google マップ、未設定なら OpenStreetMap）
- **みんなで共有**：Google ログイン → リスト作成 → 招待リンクで参加（承認なし・最大10人）。追加・編集・削除はメンバー全員の画面に即時反映
- **フォント**：源ノ角ゴシック（端末にない場合は同じデザインの Noto Sans JP を Google Fonts から読み込み）
- **オフライン対応**：電波が悪いときは端末に一時保存し、つながったら自動で送信
- **バックアップ**：JSON の書き出し・読み込み

## 使い方

1. 作成者（ルールに登録したアカウント）が公開URLを開き、Google でログイン →「新しいリストを作る」
2. 設定（右上の歯車）の **招待リンク** を一緒に使う人に送る（メンバーなら誰でも送れる）
3. リンクを開いて Google でログインすると、**承認なしですぐに参加**（1つのリストに最大10人）
4. 作成者はメンバーを外せる・招待リンクを再発行できる（古いリンクは無効になる）。作成者以外は自分で「抜ける」ことができる

招待リンクを知っている人は誰でも参加できるため、送る相手に注意すること。

Firebase の Firestore ルールには [`firestore.rules`](firestore.rules) を貼り、`ownerEmail()` を作成者の Google アカウントに書き換えて公開する
（実際のアドレスはこの公開リポジトリには書かない）。

LINE のアプリ内ブラウザでは Google ログインができないため、招待リンクには `?openExternalBrowser=1` を付けて外部ブラウザで開くようにしています。
