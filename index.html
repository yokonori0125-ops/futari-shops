Google マップ連携（APIキー）

APIキーを設定すると、マップタブが Google マップで表示され、位置検索にも Google のジオコーディングを使います。未設定のときは OpenStreetMap で表示します。

キーの取得手順（Google Cloud Console）:
  1. プロジェクトを作成し、Maps JavaScript API と Geocoding API を有効化
  2. 「認証情報」でAPIキーを作成
  3. キーの制限で「ウェブサイト」を選び、https://yokonori0125-ops.github.io/* だけを許可
キーはこの端末にのみ保存されます（相手の端末では相手が設定します）。
